# Flood AINE 🌊

### AI-Based Detection of Flood-Affected Areas in North-East India Using Satellite Images

## About the Project
Flood AINE is a student group project focused on using satellite images and AI-assisted analysis to support awareness of flood-affected areas in North-East India.

The project presents flood-related information through a simple and interactive website.

## Objectives
- Understand how satellite imagery can support flood monitoring.
- Present flood-related information in an accessible format.
- Create awareness about environmental risks in flood-prone regions.

## Key Features
- Flood Map with state-wise flood assessment.
- AI Detection dashboard.
- Visualization of flood-related information.
- Information about the methodology and environmental impact.
